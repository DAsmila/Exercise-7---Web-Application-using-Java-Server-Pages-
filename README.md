# Product Inventory Management System

A simple web-based Product Inventory Management System developed using JSP and Apache Tomcat.

## 📌 Project Description

This project demonstrates how JSP can be used to collect product information from a user, process the data on the server, calculate the total inventory value, determine stock status, and display an inventory report.

## 🚀 Features

- Accepts product details through a JSP form
- Uses `request.getParameter()` to retrieve form data
- Converts String input into numeric values
- Calculates total inventory value
- Determines stock status automatically
- Displays the inventory report in a table

## 🛠️ Technologies Used

- Java
- JSP (JavaServer Pages)
- HTML
- Apache Tomcat 10.1
- Spring Tools for Eclipse (STS)
